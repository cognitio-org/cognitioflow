CognitioFlow PR watcher

Options

Everything here stays in this Chrome profile's extension storage. It is not synced and never sent anywhere except the service it belongs to.

GitHub

Comma separated. These are checked for whether GitHub is handing out runners at all — when it stops, every pull request goes red for a reason that has nothing to do with the code. Leave blank to watch the repository above. Reading Actions billing needs an org admin scope on the token; without it you still get the runner answer, just not the minutes.

GitHub → Settings → Developer settings → Fine-grained tokens → Only select repositories: this repository. Permissions: Pull requests read and write, Contents read and write (to merge and delete the branch), Checks read, Metadata read. Nothing else.

Re-review model

Only the key for the chosen model is used. Re-review sends the PR's diff to that provider.
